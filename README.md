# 浮光橙仔 Desk Pet `v1.2.0`

一个与 VS Code 联动的 Windows 桌面宠物。

浮光橙仔会在桌面上自然闲逛、回应开发事件、提醒休息，并通过 VS Code 扩展与编辑、保存、构建、测试、调试和 Git 状态联动。除了主宠之外，还可以召唤具有不同能力的真实宠物访客，例如狗狗和训练犬。

桌面端与 VS Code 扩展通过本机 Named Pipe 通信，不依赖云服务。

## v1.2.0 更新内容

- 完成双宠访客系统
- 新增训练犬访客

- 新增训练犬截飞盘流程
- 新增训练犬专用透明动作资源
- 新增访客 Profile 与能力系统
- 支持狗狗与训练犬之间切换
- 支持访客状态、亲密度、心情和精力
- 完善高优先级事件中断和资源清理
- 完善单实例保护、显示隐藏、暂停和退出流程
- VS Code 扩展与桌面运行时同步发布

## 功能概览

### 主宠：浮光橙仔

浮光橙仔是桌面上的开发陪伴角色，支持：

- 透明背景桌面窗口
- 始终置顶或普通窗口模式
- 自动行走与待机动画
- 鼠标拖拽移动
- 拖起、落地和有限惯性反馈
- 多显示器位置恢复
- 显示器断开后的可见区域修正
- 当前帧 Alpha 命中检测
- 点击、双击和鼠标方向反馈
- 暂停或继续自动移动
- 系统托盘控制
- 显示、隐藏、退出桌宠
- 动画速度与移动速度调节
- 气泡提示、静音、自动行走和置顶开关

主宠包含待机、行走、挥手、跳跃、查看、等待、失败、被提起、落地、伸懒腰、坐下、睡觉和庆祝等状态动画。

透明区域不会响应身体点击，避免点击空白位置时误触互动。

## VS Code 联动

安装 VS Code 扩展后，编辑器事件可以驱动桌宠状态。

### IDE 到桌宠

| VS Code 事件 | 桌宠反馈 |
| --- | --- |
| 编辑文本 | 行走或编辑中状态 |
| 编辑停顿 | 回到待机状态 |
| 保存文件 | 跳跃反馈 |
| 切换活动编辑器 | 查看或观察反馈 |
| 诊断错误增多 | 失败反馈 |
| 开始构建、测试、调试或终端任务 | 等待状态 |
| 构建或测试成功 | 挥手或庆祝反馈 |
| 构建或测试失败 | 失败反馈 |
| 专注期间离开 VS Code | 低频分心提醒 |
| Git 存在未提交修改 | 低频提醒，避免重复刷屏 |

事件联动可通过设置关闭。桌面端与侧边栏 Webview 会同步使用对应的动画状态。

### 桌宠到 IDE

桌宠托盘菜单可以请求 VS Code 执行常用操作：

- 打开当前工作区
- 聚焦终端
- 打开 Problems
- 打开源代码管理
- 运行默认 Build 任务
- 运行默认 Test 任务
- 开始或停止专注

桌面端与扩展连接中断时会自动降级，不会因为 IPC 断开导致桌宠退出。

## 专注与提醒

浮光橙仔内置轻量专注计时功能，支持：

- `25/5` 和 `50/10` 专注模式
- 自定义专注和休息时长
- 暂停、恢复和停止专注
- 今日专注次数与累计分钟统计
- 一次性稍后提醒
- 久坐、喝水和护眼提醒
- 单独关闭各类提醒
- 专注期间降低主动动作频率

提醒不会强制抢占当前输入焦点。

## 访客系统

访客由 Profile 和能力声明驱动，同一时间最多显示一位访客。访客可以从系统托盘召唤，也可以送回家。

切换访客时，旧访客窗口、飞盘、食盆、球、计时器和进行中的互动都会被清理。菜单会根据当前 Profile 的能力自动显示或隐藏，不需要在主窗口中为每个物种增加独立分支。

当前已上线两个访客：

- 狗狗：`dog`
- 训练犬：`training-dog`

### 狗狗访客

狗狗是偏陪伴和玩耍的日常访客，支持：

- 摸头回应
- 玩球取回
- 找 Bug
- 嬉戏追逐
- 玩具逗弄
- 守护和安慰
- 坐下、趴下和睡觉
- 探头和藏起来
- 晨间来访与下班提醒
- 成长称号

#### 玩球取回

从托盘选择“和狗狗玩球”后，点击桌面可用位置确定落点，狗狗会跑向球、拾取球并叼球返回主宠附近。玩球会消耗狗狗精力，连续重复互动会受到冷却和收益递减限制。

#### 找 Bug

狗狗可以进入嗅闻和搜寻状态，并从桌宠打开 VS Code Problems 面板。

### 训练犬访客

训练犬是偏主动训练互动的访客，提供握手、摸头、喂食和接飞盘等玩法。

#### 握手

可以从系统托盘选择“和训练犬握手”，也可以直接左键单击训练犬：

1. 训练犬抬起前爪并进入限时邀请
2. 用户在邀请期间点击训练犬
3. 点击身体其他位置会触发疑惑反馈
4. 点击正确的前爪命中区域后进入握手成功
5. 成功后增加少量亲密度并进入冷却

握手使用局部前爪命中区域，不是整张图片点击即成功。

#### 摸头

训练犬使用右键单击触发摸头回应：

- 播放 `petting-response`
- 只对脸部进行轻微特写
- 不改变训练犬窗口的垂直位置
- 约 900ms 后恢复正常显示
- 互动完成后增加少量亲密度

#### 喂零食

零食互动没有狗粮冷却，会播放专用 `treat-eating` 动画，增加少量亲密度和心情但不恢复精力。动作播放期间不会重复重入。

#### 喂狗粮

狗粮互动包含嗅闻、低头进食和舔嘴感谢等连续动作，并恢复少量精力。狗和食盆已经合成在同一张透明动画帧中，避免独立窗口产生错层或残影。狗粮具有冷却时间，冷却期间托盘菜单会显示剩余秒数。

#### 接飞盘

用户按下并拖动确定方向与力度，释放后生成受限飞盘轨迹。训练犬会先观察飞盘方向，再跑向预测交点，成功时播放腾空接住、落地和叼盘返回，失败时播放扑空回望。

飞盘流程支持左右跑动、左右接盘、左右方向叼盘返回、近投、远投、过高、落点不可达、目标显示器约束、连续取消和高优先级事件中断。飞盘会消耗训练犬精力，低精力时训练犬会拒绝继续并进入休息状态。

## 状态与成长

主宠和访客拥有相互独立的轻量状态，包括：

- 亲密度
- 心情
- 精力
- 饱腹度
- 成长称号
- 当日统计

互动、专注完成、任务成功和访客行为会影响状态。系统不引入复杂货币、库存、付费养成或强制签到机制。养成系统可以通过托盘开关关闭，关闭后相关数值会被封存。

## 安装方式

### VS Code 插件

从 GitHub Release 下载 `fuguang-orange-pet-v1.2.0.vsix`，然后在 VS Code 中打开扩展面板，选择“从 VSIX 安装”，安装后重新加载窗口。

插件默认会自动启动内置桌面宠物，也可以通过命令面板手动启动。

### 独立桌面版

下载 Windows x64 独立压缩包，解压后运行 `Fuguang.DesktopPet.exe`。独立版不依赖 VS Code，仍支持桌面陪伴、系统托盘、访客召唤、训练犬互动、狗狗玩球、喂食、接飞盘、专注和提醒。

VS Code 联动和命令面板功能需要安装 VS Code 插件。

## VS Code 命令

在命令面板中搜索“浮光橙仔”，可使用：

- 打开桌宠
- 启动桌面宠物
- 显示桌面宠物
- 隐藏桌面宠物
- 暂停或继续桌面宠物
- 退出桌面宠物
- 开始专注
- 停止专注
- 稍后提醒我

## 扩展设置

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| `fuguangPet.autoStartDesktop` | `true` | VS Code 启动后自动启动桌宠 |
| `fuguangPet.desktopExecutable` | 空 | 独立桌宠路径；为空时使用插件内置程序 |
| `fuguangPet.eventDriven` | `true` | 是否根据编辑、保存、任务和调试事件驱动桌宠 |
| `fuguangPet.focusMinutes` | `25` | 自定义专注时长，单位为分钟 |
| `fuguangPet.breakMinutes` | `5` | 自定义休息时长，单位为分钟 |
| `fuguangPet.gitReminder` | `true` | 是否提醒当前 Git 仓库存在未提交修改 |

## 系统要求

- Windows x64
- VS Code `^1.90.0`
- VS Code 插件会使用扩展内置桌面程序
- 独立桌面版需要 Windows x64 的 .NET 8 Desktop Runtime
- 不需要联网服务或云端账号
