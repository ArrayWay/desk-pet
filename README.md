# 浮光橙仔 Desk Pet

桌面宠物 + VS Code 联动。可独立运行，也可在 VS Code 中自动启动并双向联动。

## 功能概览

- **主宠桌面陪伴**：透明置顶窗口、闲逛/待机/互动动画、拖拽与托盘控制
- **宠物访客系统**：同时最多 1 位访客玩伴；按角色能力开放不同互动
- **VS Code 联动**：编辑/保存/任务/调试等事件驱动动作；命令控制桌宠；桌宠可回控 IDE
- **专注与提醒**：专注计时、休息、稍后提醒；可选喝水/护眼/休息提醒
- **状态成长**：亲密度、心情、精力等轻量数值（访客也有独立统计）

---

## 主宠（浮光橙仔）

- 透明置顶桌面窗口，可拖动；支持自动行走与动画速度调节
- 待机 / 闲逛 / 挥手 / 跳跃 / 查看 / 等待 / 失败等状态切换
- 点击互动、托盘菜单控制：显示、隐藏、暂停/继续、退出
- 专注模式：开始 / 停止专注，记录今日专注次数与分钟
- 可选气泡提示、静音、置顶开关
- 可选休息 / 喝水 / 护眼提醒（可开关与改间隔）

## 特色：宠物访客系统

访客会偶尔来访，也可从系统托盘**主动召唤**；同一时间只显示 **1** 位访客。  
访客按 **Profile + 能力** 驱动菜单与玩法（后续可扩展猫、鸟等，当前已上线 2 个角色）。

### 已上线角色

#### 1. 狗狗（`dog`）

偏「陪伴 + 玩耍」的日常访客。

| 能力 | 说明 |
| --- | --- |
| 摸头回应（Petting） | 点击访客触发摸头反馈动画 |
| 玩球取回（Fetch） | 托盘「和狗狗玩球」：抛球 → 追逐 → 叼球返回 |
| 找 Bug（BugSearch） | 托盘「让狗狗找 Bug」：嗅闻 / 搜寻类互动反馈 |
| 嬉戏追逐（PlayfulChase） | 与主宠/屏幕内的轻量追逐互动 |
| 玩具逗弄（ToyTease） | 玩具相关逗弄行为 |
| 状态动画 | 待机、左右跑、坐卧睡、醒来伸懒腰、开心庆祝、难过、等待、守护、安慰、探头、叼球左右等 |

#### 2. 训练犬（`training-dog`）

偏「训练互动」的访客，技能与狗狗不同。

| 能力 | 说明 |
| --- | --- |
| 握手（Handshake） | 托盘「和训练犬握手」：限时邀请 + 局部命中成功动画 |
| 喂食（Feeding） | 托盘喂食：放食盆 → 嗅闻 → 进食 → 舔嘴感谢 / 吃零食等 |
| 接飞盘（FrisbeeCatch） | 托盘「和训练犬玩飞盘」：观察 → 左右奔跑 → 接住/落地/带回 或 失手 |
| 状态动画 | 半坐喘气待机、左右跑、握手邀请/成功、嗅食、进食、感谢、吃零食、飞盘观察/跑/接/落/回/失手等 |

### 访客使用方式

1. 启动桌面宠后，在 **系统托盘** 找到访客菜单
2. **召唤 / 送回家**：控制当前访客是否在场
3. **选择访客**（已注册多个角色时）：在狗狗与训练犬之间切换
   - 切换时旧访客窗口与进行中的球/飞盘/喂食会清理，只保留新访客
4. 菜单项会按角色能力自动显示/隐藏（例如狗狗显示玩球，训练犬显示飞盘/握手/喂食）

## 亮点：VS Code 联动

安装 VSIX 后，扩展与桌面宠通过本地 Named Pipe 通信，支持 **IDE → 桌宠** 与 **桌宠 → IDE**。

### IDE → 桌宠（事件驱动，可关）

设置项 `fuguangPet.eventDriven`（默认开）：

| 触发 | 桌宠反馈（示意） |
| --- | --- |
| 正在编辑文本 | `running`（编辑中） |
| 编辑停顿约 0.9s | `idle` |
| 保存文件 | `jumping` |
| 切换活动编辑器 | `review` |
| 诊断错误增多 | `failed`（提示错误数量） |
| 开始调试 / 任务 / 终端命令 | `waiting` |
| 调试/任务/终端结束成功 | `waving` |
| 结束失败 | `failed` |
| 专注期间反复离开 VS Code 窗口 | `review`（专注分心提醒） |
| Git 未提交改动（可关） | 低频 `review` 提醒（约每 30 分钟至多一次） |

侧边栏 Webview 也会同步播放对应动画；桌面宠进程会收到同样事件。

### 命令面板控制桌宠

命令均以「浮光橙仔:」开头：

- 打开桌宠（侧边栏）
- 启动 / 显示 / 隐藏 / 暂停或继续 / 退出桌面宠物
- 开始专注 / 停止专注
- 稍后提醒我（自定义分钟）

### 桌宠 → IDE（回控）

桌宠侧可发起动作，由扩展执行，例如：

- 打开文件夹
- 聚焦终端
- 打开问题面板
- 打开源代码管理（SCM）
- 运行 Build / Test 任务组

### 扩展设置

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| `fuguangPet.autoStartDesktop` | `true` | 启动 VS Code 后自动拉起桌宠 |
| `fuguangPet.desktopExecutable` | 空 | 桌宠 exe 路径；空则用扩展内置 |
| `fuguangPet.eventDriven` | `true` | 是否根据编辑/保存/任务/调试切换动作 |
| `fuguangPet.focusMinutes` | `25` | 专注时长（分钟） |
| `fuguangPet.breakMinutes` | `5` | 休息时长（分钟） |
| `fuguangPet.gitReminder` | `true` | 未提交改动低频提醒 |

要求：Windows x64，VS Code `^1.90.0`

## 两种用法

### 1. 联动版（推荐）

安装：`fuguang-orange-pet-v1.0.0-vscode.vsix`

1. VS Code → 扩展 → `...` → **从 VSIX 安装…**
2. 选择上述 VSIX，重新加载窗口
3. 默认自动启动桌面宠；也可命令面板搜索「浮光橙仔」

内置桌宠与访客资源会随 VSIX 一起提供。

### 2. 独立桌面版

解压 `Fuguang.DesktopPet-v1.0.0-windows-x64.zip`，运行 `Fuguang.DesktopPet.exe`。  
无需安装 .NET，也不依赖 VS Code（无事件联动与命令面板，仍可用托盘与访客玩法）。
